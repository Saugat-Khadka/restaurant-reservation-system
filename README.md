# Restaurant Reservation System (MERN Stack)

## Overview
This is a backend-focused restaurant reservation system built using the MERN stack architecture. It provides RESTful APIs to create and manage restaurant reservations with a modular and scalable Express.js structure.

---

## Features
- Create restaurant reservations with customer details
- Store reservation data in MongoDB
- Service-based architecture for business logic
- RESTful API built with Express.js
- Centralized error handling middleware
- CORS enabled for frontend integration
- Environment-based configuration using dotenv

---

## Reservation Data Structure
Each reservation includes:
- First Name
- Last Name
- Email
- Phone Number
- Reservation Date
- Reservation Time
- Guest Count

---

## Tech Stack
- Node.js
- Express.js
- MongoDB (Mongoose)
- CORS
- dotenv
